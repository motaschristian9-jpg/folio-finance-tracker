# Design system
Principles: clarity, action-first, progressive disclosure, visible system status, minimal copy.
Typography: Manrope headings, DM Sans body, system fallback.
Spacing: 4/8/12/16/20/24/32px rhythm. Corners: 11/17/22px.
Dark: background #0b1220, surface #121d2e, accent #c5f48e. Light: background #f6f8f7, surface #fff.
Mobile: bottom navigation, floating add action, bottom-sheet forms. Desktop: left navigation and wide dashboard. Motion: 180–400ms with prefers-reduced-motion support.
