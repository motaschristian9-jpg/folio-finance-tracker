# Product requirements — Folio
Goal: Let one person manage finances quickly and privately without internet, login, or desktop computer.
User stories: Record income/expense; see balance and monthly cash flow; search history; set category spending limits; track savings goals; view trends; back up and restore data; install on phone.
Success: First transaction in under 30 seconds; core actions available offline after initial installation; no network request needed for CRUD.
Out of scope: Cloud sync, multi-user access, bank integrations, automated currency conversion, encrypted-at-rest storage, recurring transactions.
