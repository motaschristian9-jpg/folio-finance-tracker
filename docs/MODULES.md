# Modules and build order
1. Storage: SQLite initialization, IndexedDB persistence, backup/restore.
2. Transactions: CRUD, filters, search.
3. Dashboard: totals, recent activity, spending breakdown.
4. Planning: monthly category budgets, savings goals.
5. Insights: historical summaries and six-month chart.
6. Preferences: theme, currency, export/restore, install affordance.
7. PWA: service worker, manifest, responsive shell.
