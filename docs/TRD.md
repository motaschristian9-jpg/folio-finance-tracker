# Technical decisions
React + Vite PWA, hosted as static assets on Vercel/Render static site. sql.js provides SQLite in WASM; IndexedDB stores exported database bytes after every mutation. No backend, no authentication. Service worker caches same-origin assets including the WASM after first load. Schema: transactions(id,name,amount,type,category,date,note), budgets(id,category,amount), goals(id,name,target,saved), settings(key,value). Monetary amounts use SQLite REAL for this prototype; for high-precision accounting, migrate to integer minor units. Backup and restore use raw SQLite binary files. Local data is origin-scoped and not synced.
